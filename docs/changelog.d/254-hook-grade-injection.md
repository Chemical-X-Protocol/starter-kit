### Fixed

- Pre-commit hooks: under `CHEMX_PRECOMMIT_GATE=grade`, `scripts/pre-commit.sh` and the installed hook built `--min-grade`/`--min-score` from `.chemx/config.json` or `CHEMX_MIN_GRADE`/`CHEMX_MIN_SCORE` and eval-ed the result, so a value such as `B;touch x #`, `$(...)` or a backtick payload ran at commit time. The hooks now put no config value and no floor variable into the eval-ed command (`CHEMX_BIN`, the user's own command override, still runs as before): they parse no config, `chemx audit` resolves the floors (#255), and the only floors the hooks set are their own defaults, which are always a known grade and an integer 0-100 (#254).
- `buildPreCommitHookScript` and `buildGitHubWorkflowScript` coerce the floors they render, so a malformed `minGrade` or `minScore` at install time becomes `B` / `80` instead of shell text (#254).
