### Search finds tracked dot-directories; `--max` and `--glob`; `read` shows YAML as text (#6771)

Reference: [search.md](../search.md#what-is-searched). Reported (K10, epic #6745): `chemx q -g` skipped `.github` and every other dot-path unless `--hidden`, so a search for the CI pin in `.github/workflows` found nothing; `--max` and `--glob` were unknown flags that agents reach for; `chemx read` of a long YAML file printed an empty outline.

- `q -g` (and the text fallback of `q <text>`) searches dot-directories and dotfiles by default (`.github`, `.claude`, `.chemxrc`, `.gitignore`, an untracked `.fresh/` too). Left out: what git ignores, `.git`, `node_modules`, the chemx index dir `.chemx` and `.claude/worktrees` copies. Both engines (the JS lister and ripgrep) apply the same scope.
- `--hidden` now means "also what git ignores" (it used to lift only the dot-path filter, and never reached `.claude` or `.chemx`): ignored paths, `.chemx` and the worktree copies are searched, `.git` and `node_modules` never (a pnpm app lists 110,000 files there; `--hidden` took 87 s on do-it-for-the-xp before the exception, about 35 s with the JS engine and 17 s with ripgrep after, on a busy machine). The scope line says `dot-directories searched; git-ignored paths skipped (--hidden includes them)` or `git-ignored paths included`; `skipped.hidden` keeps its name and meaning in `--json`. `q <text> --hidden` passes the flag to the fallback.
- `--max <N>` is `-n <N>`; `--glob <path>` is `--dir` (the existing path filter, no second filter). A path filter given a pattern (`--glob 'a/*.txt'`) fails with "takes paths, not patterns" and the unquoted-shell-glob form.
- `chemx read <file>` over the 100-line window with nothing to outline (yaml, json, txt, shell, sql, html, Markdown without headings, a stylesheet with nothing the outline lists) returns the first 100 lines as text with `Use chemx read <file>:101-N` for the rest. Code, PHP, Markdown with headings and stylesheets with declarations keep the outline; an explicit `--outline` is unchanged.
- `listGitFiles` takes an `isSkipped(relPath)` option (default unchanged: `.git`, `.claude`, `.chemx`), so the audit scans are not affected.
- Pinned by `search-literal-dotdirs.spec.js` (both engines), `search-args-aliases.spec.js`, `reader-plain-text.spec.js` and `git-file-listing.spec.js`.
