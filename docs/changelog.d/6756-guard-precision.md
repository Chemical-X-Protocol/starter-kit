### Guard: deny only what chemx covers, and a repo allow-list (epic #6745, K11 #6756)

Reference: [hooks.md](hooks.md#precision-deny-only-what-chemx-covers). Reported: thirteen agents on one epic were denied `git -C <worktree> log`, `git log A..B`, `git show`, recursive `grep` outside the project, `grep -c`/`-o`, `vitest --version` and `command -v`, pointed at chemx forms that lacked `--root`, ranges or counts; a compound command with one denied segment never ran and the denial did not say so; every bypassed runner call still carried a nudge; `sleep 5` was nudged toward `chemx wait`.

- A deny is kept only where the chemx call is a strict superset of the exact command: the plain `git log`, `git diff`, `git show <rev>` and `<rev>:<path>`, `grep -r`, `grep` on a source file, `find` with name tests, `cat`/`head`/`tail`/`sed` and `node --test` in the project stay denied. A piped `git diff` now names `chemx d --full`.
- A shape chemx covers in part is a nudge with the closest chemx form (`nudge-git-c`: `chemx log|d|show --root <dir>`; `nudge-git-log-range`: `chemx log -n 50 A..B`; `nudge-git-show`; `nudge-git-diff-names`: `chemx d --name-only`; `nudge-grep-count`; `nudge-grep-only`: `chemx q -g -o --unique`; `nudge-grep-outside`: `chemx q -g <path>` for a path a chemx project owns; `nudge-find`). `guardNudges: "block"` does not promote these; listing the id in `guardNudgeBlock` does.
- A shape chemx has nothing for runs silently: `grep -v/-w/-x/-L/-q/-P`, recursive grep in `node_modules` or a path no chemx project owns, `find -mtime/-size/-newer/-perm/-empty`, `tail -f`, `command -v tool`, `tool --version|-v|--help`, and `git rev-parse|rebase|push|worktree|branch|fetch|checkout` (which never had a rule; now pinned by specs).
- `sleep N` for N up to 120 is silent; it is nudged toward `chemx wait` only above 120 seconds, beside a `chemx team` call, or inside an `until`/`while` loop.
- A denied compound command names the denied segment, says the whole line did not run, and lists up to three other segments (`cd`/`export` left out).
- `.chemxrc` `guard.allow` lists command prefixes that run with no deny, no nudge and no bypass comment (matched word by word, from the command's directory up to the root); `test.runners` is its alias. `guard.plainGit: true` drops the git status/add/commit nudges.
- `chemx d --name-only` and `chemx log A..B` are documented in `chemx d --help` / `chemx log --help` (they already passed through to git); a denied `node --test <one spec>` now also names `-t "<name>"` and `--raw`.
- Pinned by `guard-precision.spec.js` (100 cases mirroring the agents' commands), `guard-rewrites.spec.js`, `claude-pre-tool.spec.js`, `guard-test-runners.spec.js` and `wrappers.spec.js`. Two existing expectations changed on purpose: `git -C apps/x diff --stat` is a nudge (was deny) and `sleep 5` is silent (was a nudge).
