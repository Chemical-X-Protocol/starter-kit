### Fixed

- Shallow-catch escalation (truth spec 4.2) still counts a write to the binding as a default as main does, except where a path provably reaches the read without it: a write in a function nothing calls, one in a callback a timer or listener API runs later, passed by a call that is its own statement (`setTimeout(() => { v = d; });`), and one that runs only while the binding is set (`if (v) v = v.trim()`), the last two in the simple position #253 describes. Those reads report HIGH; every other shape (an `if` with no `else`, a promise's `then`, `catch` or `finally`, loops, switch cases, catches, labels, invoked functions, other callbacks) keeps main's MEDIUM. A branch that runs whenever the binding is unset (`if (!v) v = d`) still supplies a default (#258).
- Guarded reads after a swallowed catch are MEDIUM instead of HIGH: an `||` whose left side holds while the binding is unset (`v == null || v.length`, `!v || v.x`), an early exit after the try (`if (!v)` with `return`, `throw`, `continue` or `break`, then the rest of the block), and a read in an `&&` chain after a link that rules out an unset binding (`if (v && v.a && v.b && v.c)`; #253 says which links do). `v || v.x` and `ok || v.x` still escalate. This changes severity only, not counts, so it needs no rule revision (#258).
