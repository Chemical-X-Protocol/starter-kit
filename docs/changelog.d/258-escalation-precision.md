### Fixed

- Shallow-catch escalation (truth spec 4.2) counts a write to the binding as a default only when nothing on the way to the try, or for a later write to the read, can skip it. A write in a closure that may never run (`setTimeout`, a nested function that is never called), or under a branch, loop, switch case or catch that may not run (`if (cond)`, `while (false)`), no longer keeps a swallowed catch at MEDIUM, so the read reports HIGH. A branch that runs whenever the binding is unset (`if (!v) v = d`) still supplies a default (#258).
- Guarded reads after a swallowed catch are MEDIUM instead of HIGH: an `||` whose left side holds while the binding is unset (`v == null || v.length`, `!v || v.x`), an early exit after the try (`if (!v)` with `return`, `throw`, `continue` or `break`, then the rest of the block), and a read in an `&&` chain after a link that rules out an unset binding (`if (v && v.a && v.b && v.c)`; #253 says which links do). `v || v.x` and `ok || v.x` still escalate. This changes severity only, not counts, so it needs no rule revision (#258).
