### Fixed

- `cli/main.js` (the audit's project config) and `cli/project-detector.js` (framework, `preset` and `dirs` for the generators) read `.chemx/config.json` through `cli/config/loader.js`, so a config with `//` or `/* */` comments no longer reads as `{}`. Before, a commented config silently dropped `minGrade`, `minScore`, `stage` and `model` from `chemx audit` (#255).
- Pre-commit grade gate (`CHEMX_PRECOMMIT_GATE=grade`): `scripts/pre-commit.sh` and the installed hook no longer grep `.chemx/config.json` for `minGrade`/`minScore`, a match that also took commented-out lines and nested keys. They run `audit --git --default-min-grade=<grade> --default-min-score=<score>` and `chemx audit` resolves the floors: the flag, then `CHEMX_MIN_GRADE`/`CHEMX_MIN_SCORE`, then the config, then the new low-precedence `--default-min-grade`/`--default-min-score`. With `CHEMX_VERBOSE=1` the hook banner now names the gate and where its floors come from, instead of floors the hook no longer resolves (#255).
- `chemx audit` skips a floor that is not `A+` to `F` or an integer from 0 to 100 and takes the next source. Before, an unknown grade became a floor that never failed and still switched off the default gate. A `minScore` of 0 in the config now counts as a floor, as it already did from the flag or the env (#255).
