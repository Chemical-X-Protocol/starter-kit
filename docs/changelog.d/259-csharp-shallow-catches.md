### Fixed

- C# `AI_SLOP_SHALLOW_CATCH` finds catches the old raw-text match missed: a block-comment-only body (`catch (Exception) { /* swallow */ }`), a body of several `//` lines, a `when` filter (`catch (Exception ex) when (ex is IOException) { }`) and a catch type with nested parentheses. Catch text inside a string or a comment, as in `Log("catch {}")`, is no longer reported. These catches take the same annotation placements as any other C# catch, and a reasonless `{ /* chemx-allow: best-effort */ }` body gets the "reason is mandatory" note (#259).
- Detection can rise, so `RULESET_VERSION` is 13 and `AI_SLOP_SHALLOW_CATCH` is at revision 13; `ERROR_SWALLOWED_EXCEPTION` stays at 12 from #257. A ratchet baseline recorded under an older ruleset adopts the current count instead of reporting a regression (#259, #253).
