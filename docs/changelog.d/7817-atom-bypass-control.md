- New audit rule `ATOM_BYPASS_CONTROL` (MEDIUM, ruleset 13) flags raw `<button>`, button-styled `<a>` and framework buttons (`<v-btn>` and friends) outside the atom directories, one violation per occurrence. Opt-in through the `.chemxrc` `atoms` block (`dirs`, `replacements`, `frameworkButtons`); the directive names the configured atom. `A11Y_CLICKABLE_NON_SEMANTIC` recommends that atom too when `atoms.replacements.button` is set (#7817).
